# Gestor de Libros

App Android (Flutter) para explorar el almacenamiento interno, leer PDF / EPUB / DOCX / TXT / MD,
renombrar (con emojis y símbolos), mover y borrar libros, y saltar al libro anterior/siguiente desde el visor.

## Compilar
1. Sube esta carpeta a un repositorio de GitHub (rama `main`).
2. Pestaña **Actions → Compilar APK** (se ejecuta sola al hacer push).
3. Descarga el artefacto `gestor-libros-apk`, instala el APK.
4. Al abrir la app, concede **Acceso a todos los archivos**.
